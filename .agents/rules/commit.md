# Commit Rules

Follow [Conventional Commits](https://www.conventionalcommits.org) for the commit message. Write commit messages in English.

**Format:** `<type>(<scope>): <description>`

- `scope` is the page name, feature name, or toolchain name change (e.g., `about`, `articles`, `markdown`, `oxlint`).
- `description` starts with a lowercase verb.

**Examples:**

```text
feat(about): implement barebones about page
chore(prettier): add `@prettier/plugin-astro` plugin
```
